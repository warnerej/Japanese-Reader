## Vision

This project is a tool that I am making to help me get into the habit of reading Japanese texts. I also have some friends who would like to use a tool like this. On top of all of that I think it's a good way for me to get better at programming. 

**Guiding principles**
- Data security is a must
- Must be easy to use
- Must be fun to work on
